# THERMOGARAGE — сайт-визитка (автономные отопители, Гомель)

Статический сайт без сборки: `index.html` + `assets/`. Можно залить на любой хостинг
(Netlify, Vercel, GitHub Pages, обычный shared-хостинг) как есть.

Локальный просмотр: `python3 -m http.server 8000` → http://localhost:8000

## Что заменить перед запуском

| Что | Где |
|---|---|
| Название `THERMOGARAGE` | `index.html` (logo, title, footer, JSON-LD) |
| Телефон `+375 (29) 000-00-00` / `+375290000000` | `index.html` — все `tel:`, Viber, JSON-LD |
| Адрес и режим работы | `index.html` — блок `#contacts` и JSON-LD |
| Telegram `username` | ссылка в контактах и `data-telegram` у формы |
| Домен `https://example.by/` | `canonical`, `og:*`, JSON-LD |

## Изображения

| Файл | Что сейчас | Чем заменить |
|---|---|---|
| `hero-heater.webp/.jpg` | кадр из макета (обрезка и апскейл, ~1470px) | оригинал того же кадра ≥2400px по ширине |
| `service-repair.webp` | фрагмент того же кадра | фото ремонта (1600×1000) |
| `service-maintenance.svg` | SVG-заглушка | фото очистки / ТО (1600×1000) |
| `work-01…04.svg` | SVG-заглушки | реальные фото работ 1200×900 + подписи в `index.html` (`#works`) |

Если меняете фото первого экрана, укажите в `data-outlet="x y"` у `<img data-hero-img>`
положение выхода горячего воздуха в долях картинки — от него идут свечение и искры.

Знаки Webasto / Eberspächer / Планар — упрощённые словесные начертания в SVG-спрайте
в начале `index.html` (`#b-webasto`, `#b-eber`, `#b-planar`). Для финала можно заменить
на официальные файлы логотипов.

## Анимация

- первый экран: построчное появление заголовка, «тепловой» блик на слове «ОТОПИТЕЛИ»,
  пульсирующее свечение и искры (canvas) у выхода отопителя, параллакс фото за курсором;
- появление блоков при прокрутке, подсветка карточек за курсором, бегущая строка;
- при `prefers-reduced-motion` вся анимация отключается.

## Акцент на ремонт и обслуживание

- блок «Отопитель не греет? Починим.» — клик по симптому заполняет заявку («Ремонт» + симптом);
- блок «ТО до морозов» с чек-листом сезонного обслуживания;
- в услугах ремонт и обслуживание — первые, крупные, с пометкой «Основное направление».

## Форма заявки

У `<form data-form>` есть атрибут `data-endpoint`:

- **пусто** (по умолчанию) — текст заявки копируется в буфер и открывается Telegram-чат;
- **URL** — заявка уходит `POST` JSON (`name, phone, car, service, message`) — например,
  на Formspree или serverless-функцию, пересылающую заявку в Telegram-бота.
